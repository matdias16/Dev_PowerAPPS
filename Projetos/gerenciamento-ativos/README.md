# Gestão de Pessoas

Desenvolvi este aplicativo no LAGEAMB para reunir, em um só lugar,
as ferramentas necessárias para a equipe de gestão de pessoas (RH) com
solicitações de editais, atualizações cadastrais de colaboradores, Fins de vínculos,
Replicação de edital para a criação de novos, Convocação de editais e Contratações diretas sem editais.

## Como funciona

1. O usuário registra a solicitação no Power Apps preenchendo um dos formulários.
2. Os dados e documentos ficam organizados no SharePoint em listas.
3. A equipe consulta o status pela lista do SharePoint, já que ela é a preferência pela administração.
4. Há o envio de notificações automatizadas para cada novo item criado nas listas do sharepoint.
