# Controle Diarias

Desenvolvi este aplicativo no LAGEAMB para reunir, em um só lugar,
uma ferramenta que fosse capaz de realizar solicitações de diárias para campos (viagens),
prestação de contas e ressarcimento de gastos em viagens.

Além disso, o aplicativo possui interação 100% via tela no powerapps. Os usuários podem fazer solicitações, verificar o andamento de suas solicitações
e também receber o retorno de comentários do administrador para ajustes.

Já o administrador, por meio da tela de controle, pode analisar as informações dos usuários, assim como seus dados pessoais e retornar comentários para ajuste, tudo isso
sem precisar consultar fontes externas.

## Como funciona

1. O usuário registra a solicitação no Power Apps preenchendo os campos dos formulários.
2. Os dados e documentos ficam organizados no SharePoint em listas.
3. A equipe responsável consulta o status pelo próprio aplicativo do powerapps na aba de controles, podendo realizar filtros e consultas, revisando, aprovando ou retornando
com comentários.
4. Há a possibilidade da exportação das informações em planilha excel, uma automatização que foi feita utilizando o power automate.
5. Há o envio de notificações automatizadas para cada novo item criado nas listas do sharepoint.
