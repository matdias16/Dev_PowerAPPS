# Emprestimo de Carros

Desenvolvi este aplicativo no LAGEAMB para reunir, em um só lugar,
uma ferramenta que fosse capaz de realizar agendamentos/reservas dos carros disponíveis
ao mesmo tempo que os administradores pudessem acompanhar e indicar quais carros deveriam ser utilizados.

## Como funciona

1. O usuário registra a solicitação no Power Apps preenchendo o formulário com a data e descrição
2. Os dados e documentos ficam organizados no SharePoint em listas.
3. A equipe responsável consulta o status pelo próprio aplicativo do powerapps na aba de supervisão
4. Por meio da tela da supervisão o administrador indica qual carro deverá ser utilizado naquela reserva, evitando conflitos, sendo apresentado somente os carros disponíveis.
5. Há o envio de notificações automatizadas para cada novo item criado nas listas do sharepoint.
